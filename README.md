# Hotel Revenue Performance Analysis
## 🎯Objective: 
This project analyzes historical daily revenue data to evaluate hotel financial performance and operational efficiency. Designed to support revenue management, it focuses on key operational metrics, room revenue composition and leakage, and incorporates forecasting to optimize pricing strategies and maximize profitability.
## 📄 Case Study: 
- **Property**: The Prime Köln - 4 stars Hotel
- **Inventory**: 500 Rooms
- **Location**: Köln Central
- **Period**: Q1 2024
## 🛠️ Tool & Data: 
- Power BI Desktop – for data modeling and visualization.
- Dataset – captures daily hotel revenue performance in Q1 2024 (including RevPAR, ADR, costs, occupancy, etc.),
